# reference_s01_skeleton 直巷参考骨架

状态：skeleton，版本0.1.0。

约20m长、4m净宽、3m净高的BOX直巷；入口/出口开放。

`world`为原生`SDF1.6`，无Fuel、贴图或网格依赖。

机体0.8×1×1m，静态放在(0,2,0.5)，只作占位；它不会自动运动。

锚点(−1.8,1,2)和(1.8,19,2)、tag与LiDAR安装位、40s直线路线都只是YAML配置，未生成实际传感器/锚点实体或ROS话题。

用于D复制并填真实内容、用于A检查包结构。

validator通过不是场景运行验收。

A随后接入统一机器人/路线/传感器/`TF/query`；D完成实际场景后将`status`改为candidate并附自己的仿真证据，不能只改标签充当完成。

本包为本次新建简化几何，不包含SubT第三方资产；替换成SubT或其他资产时记录来源、版本、修改与许可。

`preview.png` 是灰色占位图，`preview.svg` 是示意图；两者均不是 Gazebo 运行截图，D 正式交付须替换真实预览。
